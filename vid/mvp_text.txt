VID – Virtual Identification System
MVP (Minimum Viable Product) Requirements Document
🎯
1. MVP Objective
The goal of the VID MVP is to build a functional, scalable, and demo-ready
web application that validates the core architecture of a multi-tenant,
workspace-based School ERP system.
This MVP will:
Demonstrate end-to-end workflows
Validate workspace-based modular design
Enable real users (Admin, Faculty, Student) to interact
Serve as a foundation for full-scale product development
🧭
2. MVP Scope
The MVP will include only high-impact core features required to operate a
school digitally.
Included:
Multi-tenant setup (basic)
Authentication & RBAC
Core academic operations
Student lifecycle management
Fees & basic finance
Examination system
Timetable
Basic communication layer
Excluded (Post-MVP):
Advanced AI (YANTRA full features)
Transport, Hostel, Library
Advanced analytics dashboards
Marketplace integrations
